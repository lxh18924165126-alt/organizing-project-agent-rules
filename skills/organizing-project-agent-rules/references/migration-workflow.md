# Migrate 工作流

适用于根 `AGENTS.md` 已存在但需要压缩、迁移或建立直接路由的仓库。

1. 修改前完成基线盘点和统一证据账本；现有明确规则必须保留、完整迁移或语义等价合并。
2. 比较适用范围、强度、例外和验证要求后才能合并；不得用历史或迁移报告代替运行时权威位置。
3. 根保留稳定内核和短路由；领域细节下沉到实际需要的直接叶子。
4. 保持统一政策中的预算、风险、权限、AgentHub/Harness 显式触发、Superpower default-deny 与运行时配置边界。
5. 发现旧 Superpower 宽松触发时，迁移为根级 default-deny 规则，并以 `superseded-by-current-user-policy` 逐条记录原文、位置、冲突和新权威位置。
6. 第二次运行不得重复迁移、同义规则或结构性改写。
